HOW THIS APPLICATION WORKS

Click to expand

System Flow

1. SCRAPE
Fetch all active commercial vehicle listings from SGCarMart.com
(~900+ vehicles daily)
2. COMPARE
Compare today's listings with yesterday's.
Any listing that disappeared = vehicle was sold.
3. SOLD LOG
Sold vehicles are logged with full details:
Model, Year, Depreciation, Dealer, Price

Why This Method?

SGCarMart does not provide a direct "sold today" feed. The only way to detect daily sales is by comparing active listings between consecutive days. If a vehicle listing URL was present yesterday but is gone today, it means the vehicle has been sold or removed.

This comparison method also gives us complete data for each sold vehicle — because the depreciation, dealer name, and price were already captured when the vehicle was still an active listing.

How to Use

  • REFRESH DATA — Click this button to scrape all current listings from SGCarMart. This takes about 3–5 minutes. After scraping, the system automatically compares with the previous day's data to detect sold vehicles.
  • Daily Report (main table) — Shows vehicles sold on the selected date, grouped by category (Van Diesel, Van Petrol, 10FT Diesel, 14FT Diesel). Use the calendar arrows or date picker to navigate.
  • History dropdown — Jump to any date that has sold data. The number in parentheses shows how many vehicles were sold on that day.
  • Export (CSV / Excel / PDF) — Download the daily sold report in your preferred format.
  • Active Listings Data — Expand this section to see the raw active listing data that was scraped for any date.
  • SGCarMart Sold Listings — Expand this section to see all-time accumulated sold listings scraped directly from SGCarMart (avl=s). This grows over time as more sold vehicles are discovered.
  • Auto Schedule — Set a time for automatic daily scraping (e.g., 06:00 AM). The server will scrape and detect sold vehicles automatically every day.
  • Clear button — Deletes sold data for a specific date. Use this if the data looks incorrect, then re-scrape.

Important Notes

  • You need at least 2 consecutive days of scrape data before sold detection works. The first scrape only saves active listings — there is nothing to compare yet.
  • Both days' scrapes must complete successfully. If one day fails (e.g., Cloudflare blocks), sold detection is skipped for that day.
  • The server must stay running for the auto-schedule to work. If the server restarts, the scheduler resumes from saved settings.
  • Each sold entry shows the data from the last time it was seen as active, so depreciation and price are always accurate.
Tip: For best results, run the scraper at the same time every day (e.g., 6:00 AM via auto-schedule). This ensures consistent daily comparison and accurate sold detection.
